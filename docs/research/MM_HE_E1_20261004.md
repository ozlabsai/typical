# Multimodal + Hebrew E1 — 2026-10-04

## Decision

Do not promote E1 or spend on seeds 1/2. The frozen-LoRA native head learned a
strong visual probe and improved Hebrew, but it failed the predeclared core-text
retention gate and the operational mismatch-image abstention test.

The next experiment should change the training signal, not add attention: train
mismatched-image null rows, strengthen text replay/retention, and isolate Hebrew
with the matched H=0 ablation. Only then consider CLM-style staged hard-negative
refinement or unfreezing language LoRA.

## What came from the reference audit

- Cygnet, Intern-Decision, and Together motivated the locked, same-backbone direct
  option-letter baseline and fitted temperature.
- Strands and Decision 2.0 supported retaining Typical's candidate/query head
  rather than adding a new fixed-slot classifier.
- Clef, Jev-Omni, Winnow, and Intern-Decision supported using Qwen3.5's native
  visual prefix rather than a separate visual classifier.
- CLM, Winnow, and Bandits motivated broad replay, counterfactual controls, and
  explicit null/quarantine semantics. This run used replay and controls; it did
  not yet add a contrastive loss or outcome-trace mining.
- Open-Jev and typed-decisions remained held-out regression suites. They were not
  indiscriminately folded into the new V/H data.
- The Hebrew extension used aligned MASSIVE Hebrew/English decisions and paired
  probability diagnostics. A consistency loss remains unimplemented.

Clef-style cross-field attention was deliberately deferred: this single-question
failure is in retention and mismatch-null supervision, not evidence routing across
multiple dependent fields.

## Results

The direct and smoke controls use the same 128-row pilot slice. E1 uses the larger
held-out split capped at 512 rows, so its row is evidence about the scaled run but
is not a paired comparison with the two controls. Probabilities are calibrated.

| System | real image | no image | shuffled | answerability AUROC | gold-dropped null recall | mismatch null recall |
|---|---:|---:|---:|---:|---:|---:|
| direct Qwen3.5 letters | .898 | .727 | .617 | .819 | .695 | .258 |
| 200-step smoke | .898 | .641 | .617 | .822 | .680 | .164 |
| E1 step 1500 | **.949** | .469 | .613 | **.844** | **.844** | **.105** |

E1 reaches 94.9% real-image accuracy and has a 33.6-point real-vs-shuffled gap, so
the existing head can use pixels. The matched 128-row smoke/direct comparison also
passes the direct-retention screen (`.898` versus `.898`). The aggregate
answerability AUROC passes the `.75` screen, but it hides the important failure:
E1 abstains on only 10.5% of deliberately mismatched image/question pairs and is
confidently wrong on 51.8% of them.

On the aligned 128-row MASSIVE slice:

| Checkpoint | Hebrew accuracy | English accuracy | pair agreement | mean pair JSD |
|---|---:|---:|---:|---:|
| `tm2` | .727 | .883 | .758 | .101 |
| smoke | .797 | .891 | .805 | .093 |
| E1 step 1500 | **.820** | .867 | .797 | **.079** |

The Hebrew gain is real enough to continue investigating, but E1 loses 2.3 points
of paired English accuracy versus the smoke checkpoint. A matched H=0 run is still
required before attributing the gain to Hebrew examples rather than continuation.

Exact 512-row text comparisons use identical rows:

| Suite | `tm2` accuracy / NLL | E1 accuracy / NLL | accuracy delta |
|---|---:|---:|---:|
| WH validation | .924 / .202 | .918 / .204 | -.006 |
| U validation | .902 / .506 | .902 / .506 | .000 |
| typed-decisions | .373 / 1.302 | .340 / 1.337 | -.033 |
| Jev-4B adversarial | .797 / .573 | .801 / .563 | +.004 |

JevBench standard/easy/hard accuracy moved from `.861/1.000/.486` to
`.819/1.000/.468`. Together with the typed-decisions drop, this fails the retention
gate even though WH and U are effectively retained.

## Next run

1. Add mismatch-image null rows to training; keep gold-dropped and shuffled controls.
2. Increase effective broad replay or add a frozen-`tm2` KL retention term on text.
3. Run the H=0 isolation at the smallest budget that resolves the Hebrew effect.
4. Gate every checkpoint on mismatch null recall plus typed-decisions and JevBench,
   not only mean validation NLL.
5. Keep attention, extra seeds, and LoRA unfreezing blocked until this recipe passes.
