# R055: make Typical the best 9–14B decision model in Hebrew (12-hour sprint)

Start 2026-10-20 19:14 UTC. Hard deadline 2026-10-21 07:14 UTC.

## Target
Beat every 9–14B open decision model on Hebrew, without losing English. Peers: Cygnet, Winnow-12B, clef-flash, StartLux-9B, torchcast-12b.
- **Primary test:** Hebrew JevBench v0, the translated, mixed and native sets (eval-only).
- **Independent test:** an external Hebrew panel built from public test splits: Belebele-he, HebNLI gold, Global-MMLU-he, HebrewSentiment, Winograd-he, HeQ.
- **Guardrails:** English public JevBench 231 must lose ≤ 1 pt vs R044-R; MASSIVE-he/en and image retention must lose ≤ 2/128.
- **Selection:** use only a Hebrew dev split carved from the training distribution, never the test sets.

## Data, built in parallel on CPU (H0–H3)
- **D1 translated twins:** ~5k of our own English decision items, translated by claude-haiku-5-5. Each item becomes a Hebrew version and a mixed version; gold labels carry over. Numbers and labels are checked automatically, and a strong model spot-checks a sample.
- **D2 native and open:**
  - Open Hebrew train splits: MASSIVE-he, HeQ, HebrewSentiment.
  - ~2.5k native Hebrew cases grounded in Israeli law text, MFAQ-he and data.gov.il tenders, generated by Haiku.
  - Labels from Qwen3.8-27B thinking on the GPU, kept only where they agree with the generator's intended answer.
- **D3 trainer:** an optional twin-consistency loss, a symmetric KL between EN and HE option distributions.
- **Contamination:** deduplicate every training row against all test sets.

## GPU (H3–H10, one pod)
1. Qwen labels for the native items. Peers and R044-R run on the external panel.
2. Train fresh Gemma-4-12B-it LoRA arms, ~20k presentations each with ~50% Hebrew plus English and image replay:
   - **A:** plain supervised (soft targets).
   - **B:** A plus twin consistency.
3. Evaluate both arms on all test sets and guardrails. The winner is chosen on the Hebrew dev split.

## H10–H12
Buffer, the final report and the commit.
